# WP Hockey Predictor — Public Pick Archive

**Every NHL pick we publish, locked in before puck drop, with the timestamp to prove it.**

This repository is the tamper-evident public record of [WP Hockey Predictor](https://www.wphockeypredictor.com)'s automated NHL picks. Before every game, our model's final picks are emailed to subscribers and — in the same minute — committed here. The commit timestamp is applied and attested by GitHub's infrastructure, not by us, which makes this archive something most picks services can't offer: **independent, third-party proof of what we predicted and when**.

No picks are added after the fact. No losses are quietly removed. The graded result of every pick is committed the morning after the game, win or lose.

---

## How the archive works

| When (ET) | What is committed | Where |
|---|---|---|
| ~15 min before each game's puck drop | The locked pick, exactly as emailed to subscribers | `picks/<YYYY>/<MM>/<YYYY-MM-DD>.json` |
| ~3 AM the next morning | Graded results for the completed slate | `results/<YYYY>/<MM>/<YYYY-MM-DD>.json` |

Commit messages follow a fixed pattern — `WP picks for 2026-06-14 (1 game)` / `WP results for 2026-06-14 (1 game)` — so the [commit history](../../commits/main) reads as a chronological ledger.

## Verify a pick yourself

1. Open any file under [`picks/`](../../tree/main/picks) and note the game's `game_date` and `game_time_et`.
2. Click the **History** button on that file and check the commit's timestamp (shown in UTC). It will precede the game's start time.
3. Each pick also carries `finalized_at_unix` — the exact second the pick was locked on our servers, which you can compare against the commit time.
4. Open the matching file under [`results/`](../../tree/main/results) to see how the pick graded.

Because git history is content-addressed, editing an old pick would change every subsequent commit hash — any rewrite of history would be visible to anyone who has ever cloned or watched this repository.

## Tally the record yourself

Don't take a marketing page's word for a win rate — compute it from this repo:

```bash
git clone https://github.com/Aiello89/wphp-pick-archive
cd wphp-pick-archive
python3 - <<'EOF'
import json, pathlib
wins = losses = 0
for f in pathlib.Path("results").rglob("*.json"):
    for g in json.loads(f.read_text()):
        r = str(g.get("pick_result", "")).lower()
        wins += (r == "win")
        losses += (r == "loss")
total = wins + losses
print(f"{wins}W - {losses}L  ({wins/total*100:.1f}%)  across {total} graded picks")
EOF
```

The same numbers are shown live at [wphockeypredictor.com's track record](https://www.wphockeypredictor.com/track-record), which is generated from the same grading pipeline.

## What's in a pick file

Each `picks/.../<date>.json` is a list of games. Per game:

| Field | Meaning |
|---|---|
| `wp_pick`, `wp_pick_team` | The model's pick (e.g. `"Hurricanes moneyline"`) |
| `confidence_tier` | Public confidence label (`Lean` / `Confident` / `Strong` / `Lock`) |
| `is_pick_of_day`, `potd_reasoning` | Pick of the Day flag and its one-line rationale |
| `away_ml`, `home_ml`, `pick_odds`, `pick_odds_type` | Market moneylines at lock time |
| `over_under` | Game-total prediction |
| `away_goalscorer`, `home_goalscorer` | Anytime-goalscorer predictions |
| `away_dark_horse`, `home_dark_horse` | Dark-horse (value) goalscorer picks |
| `away_goalie`, `home_goalie`, `*_goalie_gsaa` | Confirmed starting goalies with GSAA |
| `away_b2b`, `home_b2b` | Back-to-back status |
| `is_underdog_pick`, `is_strong_favourite` | Situational badges |
| `game_date`, `game_time_et`, `finalized_at_unix` | When the game starts and when the pick locked |

Result files record, per game: the final score and the graded `pick_result` (`win`/`loss`) alongside the pick it grades.

> **Note on probabilities:** the model's raw win probabilities are intentionally not published — the public record uses confidence tiers. Everything a subscriber sees is here; the model internals are not.

## About the model

Picks are generated by an automated pipeline — no human overrides — combining team analytics (Corsi, expected goals, high-danger chances), confirmed starting-goalie performance (SV%, GSAA), injury impact, back-to-back fatigue, and recent form. Picks lock when starting goalies are confirmed, roughly 15 minutes before puck drop. Methodology overview: [wphockeypredictor.com/faq](https://www.wphockeypredictor.com/faq).

The same system powers our [iOS app](https://apps.apple.com/app/id6786436420) and the daily analysis articles on the site.
